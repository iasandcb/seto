# 세토 iPhone 앱

iOS 16 이상을 위한 SwiftUI 안내·연습 앱과 UIKit 키보드 확장입니다.
`Sources/Sebeol390Core`를 macOS 입력기와 공유합니다. SSH 터미널은 SwiftTerm과 SwiftNIO SSH를 사용합니다.

## 실행

1. Xcode에서 `iOS/Sebeol390.xcodeproj`를 엽니다.
2. `Sebeol390` 스킴과 아이폰 또는 시뮬레이터를 선택합니다.
3. 실기기는 앱과 `Sebeol390Keyboard` 타깃의 Signing & Capabilities에서 본인의 Team을 선택합니다. 필요하면 두 Bundle Identifier를 고유한 값으로 바꾸되 확장의 식별자는 앱 식별자 아래에 둡니다.
4. Run으로 설치합니다.
5. 아이폰 설정 → 일반 → 키보드 → 키보드 → 새로운 키보드 추가 → 세토를 선택합니다.
6. 앱의 연습장은 자체 터치 자판을 사용하므로 누르면 바로 세토로 입력할 수 있습니다. 다른 앱에서는 지구본을 길게 눌러 세토를 선택합니다.

전체 접근 허용은 필요하지 않습니다. 확장에는 네트워크 접근이나 오타 기록을 넣지 않았습니다.
연습장 내용은 안내 앱의 UserDefaults에 저장되며 지우기로 삭제할 수 있습니다.
자동 전환 설정은 키보드 확장 자체의 UserDefaults에 저장합니다.

## 조작

기본 연습장·최대화 연습장·mark-vector 편집창에 **현재 입력 모드**와 **자동 한/영** 스위치가 표시됩니다.
모드 표시를 누르면 한글·영문을 직접 전환합니다. 자동 변환 설정과 확정 모드는 앱 안의 모든
입력창에서 공유·저장되며, 커서 이동·화면 전환·앱 재실행 뒤에도 유지됩니다.
앱의 터치 자판·하드웨어 입력은 같은 Session을 사용하므로 표시된 모드·자동 변환 설정이
두 입력 방식에 동일하게 적용됩니다. 다른 앱에서 쓰는 키보드 확장의 설정은 별도입니다.

연습장 제목 옆 **최대화**를 누르면 입력장이 화면 전체로 펼쳐집니다.
상단 **축소**로 안내 화면으로 돌아오며 입력 내용은 두 화면에서 공유됩니다.
일반 화면의 **내용 복사** 또는 최대화 화면 상단의 복사 아이콘으로 입력창 전체 내용을 복사합니다.
복사가 끝나면 잠시 체크 표시가 나타나며, 입력창이 비어 있으면 버튼은 비활성화됩니다.

- 맨 위 숫자 전용 행은 한·영 모드에 관계없이 0–9를 바로 입력합니다. 숫자 옆의 작은 QWERTY 기호 `!@#$%^&*()`는 Shift를 누른 뒤 입력할 수 있습니다.
- 각 글쇠는 한글·영문을 함께 표시하며 현재 모드는 크고 진하게, 다른 모드는 작고 흐리게 표시합니다.
- 소프트웨어 자판은 기본 한글 두벌식 배열(ㅂㅈㄷㄱㅅㅛㅕㅑㅐㅔ / ㅁㄴㅇㄹㅎㅗㅓㅏㅣ / ㅋㅌㅊㅍㅠㅜㅡ)입니다. 하드웨어 키보드는 세벌식 390을 유지합니다.
- ⇧: 다음 글쇠의 쌍자음·ㅒ·ㅖ 또는 영문 대문자·숫자 행 기호를 입력합니다.
- #: 일반 숫자·기호 자판으로 전환합니다. 다시 누르면 두벌식으로 돌아옵니다.
- 간격 오른쪽의 `.`과 `?`는 모드와 관계없이 마침표·물음표를 입력합니다.
- ↔: 엔진의 언어 전환·직전 자동 변환 되돌리기입니다. 길게 누르면 자동 한영 전환 상태를 확인하고 켜거나 끕니다.
- 상단 문구 바: `＋`로 문구를 입력하고 저장합니다. 저장된 문구를 누르면 본문에 즉시 입력되며 길게 누르면 수정·삭제할 수 있습니다. 문구가 많으면 가로로 스크롤합니다.
- 단어 입력 중에는 같은 상단 줄에 자동완성·오타 후보를 최대 3개 표시합니다. 후보를 누르면 현재 어절을 바꾸거나, 공백 뒤의 다음 단어 후보면 그 단어를 이어서 넣습니다. 후보가 없으면 문구를 표시합니다. 왼쪽 **문구**로 입력 중에도 저장 문구를 열고 **추천**으로 돌아올 수 있습니다. 키보드 높이는 그대로입니다. 한글은 조합 중 자모까지 두벌식 키열로 비교하고, 영문은 사전 접두사와 한 글자 오타를 찾습니다. 후보 계산은 기기 안에서 수행합니다. 공백·구두점·줄바꿈으로 확정한 한글·영문 단어의 횟수와 최근 사용은 키보드 확장의 UserDefaults에 저장하며, 앱 그룹이 Info.plist `SebeolAppGroup`으로 설정된 경우에만 그 suite를 사용합니다. 같은 접두사의 학습 단어는 한 글자·한 음절부터 사전 후보보다 앞에 둡니다. 공백 뒤에는 자주 이어서 친 단어를 제안할 수 있습니다. 암호·보안 입력란은 학습하지 않고 개인 후보도 보이지 않습니다. 저장 개수는 400개로 제한하고, 한 번만 쓰인 지 30일이 지난 항목과 점수가 낮은 항목부터 지웁니다.
- 지구본: 다른 키보드로 이동하거나 키보드 목록을 엽니다.

암호·일부 전화번호 입력란과 외부 키보드를 허용하지 않는 앱에서는 시스템 키보드가 사용됩니다.
### 하드웨어 키보드

앱의 연습장을 누르면 Bluetooth·USB 키보드로 즉시 세벌식 390을 입력할 수 있습니다.
터치 키보드 확장을 활성화하지 않아도 앱 안의 하드웨어 입력은 동작합니다.

- 물리 QWERTY 위치 기준으로 입력하므로 시스템 자판의 문자 매핑에 의존하지 않습니다.
- Shift+Space로 현재 단어의 읽기를 바꾸거나 직전 자동 변환을 되돌립니다.
- Backspace는 조합 중 자모를 하나씩 지우고, 조합 밖에서는 일반 삭제를 합니다.
- 방향키·Enter·Tab·Esc와 Command/Control/Option 조합은 기본 편집기에 넘깁니다.
- 선택 영역 교체, 붙여넣기와 커서 이동 시 이전 입력 세션을 초기화합니다.
- Caps Lock은 시스템 설정과 충돌할 수 있어 전환 키로 가로채지 않습니다.

지원 범위는 **세토 앱의 연습장**입니다. iOS 공개 API에는 다른 앱의 하드웨어 키 이벤트를
키보드 확장에 전달하거나 시스템 하드웨어 입력기로 등록하는 기능이 없습니다.
앱의 자동 한/영 전환은 기본으로 켜지며, 앱 화면의 스위치 설정을 사용합니다. 확장 설정과는 별도로 동작합니다.

## Xcode Cloud

`ci_scripts/ci_post_clone.sh`는 SwiftTerm 빌드 플러그인을 사용할 수 있도록 Xcode Cloud의 패키지 플러그인·매크로 지문 검증을 건너뜁니다. 프로젝트 파일은 저장소에 포함되어 있어 재생성하지 않습니다.
빌드 번호는 Xcode Cloud가 내보내기 시 덮어쓰므로 App Store Connect › Xcode Cloud › 설정(Settings) › 빌드 번호(Build Number)에서 관리합니다.

## 검증

```sh
# Xcode가 활성 개발자 디렉터리가 아닌 경우 명령 앞에
# DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer 를 붙입니다.
xcodebuild -project iOS/Sebeol390.xcodeproj -scheme Sebeol390 \
  -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath /tmp/sebeol390-ios-build CODE_SIGNING_ALLOWED=NO build
swift test
# 부팅된 시뮬레이터 이름 또는 ID를 지정하여 UIKit 통합 테스트를 실행합니다.
xcodebuild -project iOS/Sebeol390.xcodeproj -scheme Sebeol390 \
  -destination 'platform=iOS Simulator,name=iPhone 18 Pro' \
  -derivedDataPath /tmp/sebeol390-ios-build CODE_SIGNING_ALLOWED=YES CODE_SIGN_IDENTITY=- test
```

키체인 테스트에는 시뮬레이터용 임시 서명이 필요합니다. 서명을 끄면 키체인 접근이 `-34018`로 실패합니다.

`HardwareKeymapTests`는 물리 키 매핑·Shift·단축키 통과·조합을 검증합니다.
`HardwareTextEditorTests`는 시뮬레이터의 실제 UITextView에서 조합·자모 삭제·언어 전환·이모지 보존·커서 이동·선택 영역 교체·붙여넣기 후 입력을 검증합니다.
`KeyboardReplacementTests`는 이모지·한글의 글자 단위 교체와 엔진 입력·삭제·전환 결과의 재생을 검증합니다.
iOS 확장에는 marked text API가 없어 조합 결과의 변경된 접미사만 삭제·삽입합니다.
커서·선택 영역·입력 문맥이 바뀌거나 확장이 닫히면 세션을 초기화하고, 삭제 직전 문맥이 맞는지 확인합니다.
문맥을 제공하지 않는 입력란에서는 기존 텍스트를 안전하게 교체할 수 없어 조합을 초기화합니다.

실기기에서 빠른 연속 입력, 커서 이동, 선택 후 입력, 앱 전환, 가로 화면과 VoiceOver를 확인해야 합니다.
App Store 배포용 아이콘·서명·심사 준비는 별도입니다.

## 프로젝트 재생성

프로젝트는 저장소에 포함되어 있으므로 바로 열 수 있습니다. 코어 파일을 추가한 경우:

```sh
python3 iOS/scripts/generate-project.py
```

수동으로 변경한 프로젝트 설정과 Info.plist는 재생성 시 덮어써집니다.
단어 목록과 해당 라이선스·NOTICE는 앱과 확장 번들에 함께 포함됩니다.

## mark-vector 연동

앱 첫 화면에서 **mark-vector 문서 열기**를 누릅니다. 기본 서버는
`https://markvector.fly.dev`이며 HTTPS 서버 주소를 바꿀 수 있습니다.

1. 앱 안의 웹 화면에서 mark-vector에 로그인합니다. 세션은 WebKit 저장소에 유지됩니다.
2. 프로젝트·폴더에서 문서를 선택합니다. 웹에서 편집했다면 먼저 웹의 저장 버튼을 누릅니다.
3. 상단 **세토로 편집**을 누르면 저장된 문서를 화면 전체의 네이티브 편집창으로 가져옵니다.
4. 하드웨어 키보드로 입력하면 WebSocket으로 서버에 자동 저장되고 맥의 같은 문서와 미리보기에 즉시 반영됩니다. **저장** 또는 **⌘S**는 현재 내용의 서버 저장 완료를 확인합니다.
   복사 아이콘으로 전체 내용을 복사할 수도 있습니다.

일반 프로젝트 문서를 지원합니다. 전역 시스템 프롬프트·공용 수식 문서 등은 웹에서 편집합니다.
문서 열기·HTTP 저장 요청은 로그인한 웹 페이지와 같은 출처에서 실행됩니다.
실시간 연결은 WebKit 저장소의 해당 서버 세션 쿠키를 메모리에서만 읽어 네이티브
URLSessionWebSocketTask에 전달합니다. 비밀번호나 별도의 API 토큰을 보관하지 않습니다.
키보드 확장은 서버에 접속하지 않습니다.

네이티브 편집 중 변경 내용은 서버·문서별로 앱의 UserDefaults에 복구용으로 보관합니다.
같은 문서를 다시 열면 복구하며, 서버의 저장 완료 ACK를 받은 최신 내용의 복구 사본을 지웁니다.
약 60ms 간격으로 최신 입력을 합쳐 보내며, ACK를 기다리는 동안 새 입력을 로컬에 유지합니다.
연결이 끊기면 입력은 계속할 수 있고 재연결 시 최신 스냅샷을 전송합니다. 상태는 편집창
아래에 표시합니다. 서버가 저장을 확인하기 전에는 ‘저장됨’으로 표시하지 않습니다.
앱이 백그라운드로 가면 연결을 닫고 복귀 시 다시 연결합니다.

아이폰 한 대를 편집 주체로 사용합니다. 여러 작성자의 변경 병합은 지원하지 않습니다.
맥에서는 같은 문서를 열어 두고 웹 탭을 한 번 새로고침하면 실시간 내용을 볼 수 있습니다.
맥에 미저장 수정이 있으면 먼저 저장하거나 해당 수정을 정리해야 실시간 구독이 반영됩니다.
실시간 스냅샷은 전용 인증 경로로만 전달하며 공개 라이브·안경 채널로 보내지 않습니다.

`MarkVectorIntegrationTests`는 실제 WKWebView의 모의 서버 응답으로 문서 열기·URL 인코딩·
저장·버전 충돌·웹 미저장 문서 보호를 검증합니다. 실제 서비스의 로그인과 저장은 사용자
아이폰에서 확인해야 합니다. 앱은 LLM 전송을 자동 실행하지 않습니다.

`MarkVectorLiveSyncTests`는 전송 대기 중 입력 병합, ACK 순서, 재연결 스냅샷과 저장 완료 판정을 검증합니다.


## macOS 코어 반영

아이폰 앱과 키보드 확장은 `Sources/Sebeol390Core/*.swift`를 직접 빌드하고,
macOS와 같은 `Resources` 사전 파일을 번들에 포함합니다. 별도 복사본이나 이전 버전 엔진을
두지 않으므로 확정 모드 유지·구두점 자모·짧은 셸 명령 인식 등 현재 맥 코어의 개선이
아이폰 빌드에도 그대로 적용됩니다. 코어 파일 추가 시 프로젝트 재생성을 실행합니다.
`InputSettingsTests`는 설정 초기화 회귀, 수동 전환 시 기존 글 보존, 앱 터치 입력의
최신 코어 결과와 모드 표시 갱신을 검증합니다.

## 키보드 확장 사전 메모리

확장은 `Lexicon.loadForKeyboard`로 정렬된 UTF-8 사전을 메모리 매핑하고 줄 오프셋만 보관합니다.
전체 영문 사전의 복수형 확장과 한국어 유효 단어 목록 정렬은 프로젝트 생성 시 수행합니다.
`python3 iOS/scripts/generate-project.py`를 실행하면 `iOS/Keyboard/Resources`도 갱신됩니다.
앱·macOS의 기존 사전과 단어·접두사·교정 후보를 동일하게 유지하며, 큰 String 배열과 Set을
확장 시작 시 만들지 않습니다. `KeyboardLexiconTests`에서 두 로더의 결과를 비교합니다.

TestFlight 빌드 2에는 이 메모리 개선과 작은 화면의 하단 구두점 키 폭 조정이 포함됩니다.
실기기의 확장 종료 원인은 기기 진단 로그로 확인해야 하며, 이 변경만으로 종료 해결을 확정하지 않습니다.

TestFlight 빌드 3부터 터치 자판은 두벌식 조합을 사용합니다. 세벌식용 오타 교정은 터치 입력에는 적용하지 않으며, 하드웨어 입력의 기존 조합·교정은 유지합니다.

확장 초기화 시 `UITextDocumentProxy.documentIdentifier`는 읽지 않습니다. 호스트 연결 전 UIKit이 nil을 반환하면 Swift UUID 브리지에서 종료될 수 있으며, 실기기 충돌 로그의 `KeyboardViewController.reset → UUID._unconditionallyBridgeFromObjectiveC`로 확인했습니다. 입력 문맥·선택 영역과 화면 수명 주기로 세션을 동기화합니다.

문구 바는 28pt 높이이며 등록 중에는 같은 터치 자판으로 문구를 편집하고 본문은 변경하지 않습니다. 문구는 키보드 확장 자체의 UserDefaults에 저장됩니다. 앱 내 연습장의 문구 저장소는 별도이며 전체 접근 허용은 필요하지 않습니다.

## SSH 터미널

첫 화면의 **SSH 터미널**에서 호스트 또는 `ssh://user@host:port`를 입력합니다.
비밀번호 인증과 여러 SSH 탭을 지원합니다. 각 탭은 독립적인 셸 세션입니다.
**저장한 서버**에서 서버를 선택하면 연결 정보가 채워지며, **연결**을 눌러 접속합니다.
**새 서버**로 이름·주소·사용자를 입력하고 **서버 저장**으로 등록할 수 있습니다.
선택한 서버는 **서버 변경 저장**으로 수정하고, 목록을 왼쪽으로 밀거나 길게 눌러 삭제합니다.
연결할 때도 서버 정보와 비밀번호 저장 설정을 저장합니다. 같은 주소·포트·사용자는 중복 등록하지 않습니다.
기존 마지막 접속 정보는 처음 한 번 목록으로 가져옵니다. 목록은 모든 탭에서 공유합니다.

**비밀번호 저장**은 기본으로 꺼져 있습니다. 켜면 앱 전용 iOS 키체인에 저장하고,
서버를 다시 선택할 때 채웁니다. 비밀번호는 잠금 해제 상태에서만 읽을 수 있고 이 기기에만
보관하며 iCloud로 동기화하지 않습니다. 서버 정보만 UserDefaults에 저장합니다.
SSH 비밀번호 입력란은 iOS 암호 앱의 저장 제안 대상에서 제외하도록 설정하며,
입력 가림 처리와 앱 자체 키체인 저장을 사용합니다.
저장 옵션을 끄고 **서버 변경 저장**을 누르거나 서버를 삭제하면 키체인 비밀번호도 삭제합니다.
주소·포트·사용자를 바꾸면 불러온 비밀번호는 비워지므로 다시 입력하세요.
`SSHServerStoreTests`는 목록 유지·기존 정보 이전·비밀번호 분리·수정과 삭제·키체인 실패 처리 및
실제 키체인의 저장·갱신·삭제를 검증합니다.
서버 키는 첫 접속에 SHA256 지문을 확인한 뒤 저장하며, 이후 키가 달라지면 연결을 차단합니다.
신뢰한 키는 앱의 로컬 UserDefaults에 저장합니다.

하드웨어 입력은 시스템 문자 배열과 독립적인 물리 키 위치를 기존 세벌식 390 엔진에 전달합니다.
기본은 한글 모드이며 **Shift+Space** 또는 하단 모드 버튼으로 한영 전환합니다.
한글 단어는 아래 조합 영역에서 작성하고 공백·Enter·제어 키·확정 버튼으로 전송합니다.
조합 중 Backspace는 로컬 자모를 삭제하고, 조합이 없으면 서버에 삭제 키를 보냅니다.
자동 한영은 기본으로 켜지며 상단 스위치로 끌 수 있습니다. 자동 한영이 켜져 있으면 영문도 단어를 로컬에서 판정한 뒤 전송합니다. 자동 한영을 끈 영문 모드에서는 글쇠를 즉시 전송합니다. 오타 교정은 끈 상태입니다.
터미널 글꼴은 앱에 포함한 D2Coding 18pt이며, OFL 라이선스도 번들에 포함합니다.
Ctrl·Option·방향키 등의 터미널 인코딩은 SwiftTerm에 전달합니다.
소프트웨어 입력은 현재 시스템 키보드를 사용합니다.

연결이 끊기면 전송 실패한 명령을 자동으로 재생하지 않습니다. 앱이 백그라운드에 들어가면
연결을 닫으며, 다시 접속하려면 연결 종료 후 새로 연결합니다. 원격 작업 보존에는 tmux를 사용할 수 있습니다.
원격 프로그램의 클립보드 쓰기는 허용하지 않습니다.

SwiftTerm과 SwiftNIO SSH를 앱 타깃에만 SPM으로 연결했습니다. 버전은 Package.resolved와
프로젝트 생성 스크립트에 고정됩니다. SwiftTerm은 빌드 정보 생성 플러그인을 사용하므로
Xcode 최초 빌드에서 해당 플러그인을 확인하고 활성화해야 합니다.
SwiftTerm SSH 예제에서 파생한 연결 코드의 MIT 라이선스는
`App/ThirdParty/SwiftTerm-LICENSE.txt`에 포함되며 앱 번들에도 들어갑니다.

`TerminalInputTests`는 조합 중 전송 억제, 자모 삭제, 영문 즉시 전송, 경계 확정 및
미전송 단어의 한영 전환을 검증합니다. 실기기의 빠른 키 반복·시스템 단축키 충돌과
실제 서버의 vim/tmux 조작은 별도 확인이 필요합니다.

### 외부 키보드 자판 선택

연습장·문서 편집창의 키보드 메뉴에서 **두벌식 / 세벌식 390 / 세벌식 최종**을 선택합니다.
SSH 터미널의 세로 화면에서는 상단 키보드 메뉴, 가로 화면에서는 하단 (…) 메뉴에서 선택합니다.
선택은 앱에 저장되며 모든 네이티브 입력창과 SSH 터미널에서 공유합니다.
자판을 바꾸면 현재 조합을 확정하고 새 자판으로 전환하며, 커서 이동·재연결 후에도 선택을 유지합니다.
터치 자판과 키보드 확장은 기본 두벌식을 사용합니다. 확장에는 iOS가 외부 키보드 이벤트를 전달하지 않습니다.
가로 SSH 화면은 제목·상태줄을 숨기고 조작부·조합 표시를 36pt 한 줄로 합쳐 출력 높이를 확보합니다.

### 전력 사용 비교

실기기 장시간 입력·SSH 사용 비교에는 최적화된 `Release` 빌드를 사용합니다.
개발용 `Debug` 빌드에서 발열을 관찰한 것만으로 원인을 확정하지 않습니다.
터미널 종료 시 네트워크 연결 외에 SwiftTerm의 `updateUiClosed()`로 화면 갱신 자원을 해제합니다.
앱 비활성화·포커스 해제·키보드 분리 시 로컬 및 터미널 제어키 반복 입력도 함께 취소합니다.
`TerminalLifecycleTests`는 닫힌 터미널과 입력 호스트가 실제로 해제되는지 검증합니다.

### SSH 파일 네이티브 편집

원격 도우미를 설치하고 터미널의 문서 메뉴에서 **파일 편집 연결**을 누른 뒤
`seto test.md`를 실행하면 앱의 세벌식 네이티브 편집기로 엽니다. 없는 파일은 빈 문서로 열고
처음 **저장 / ⌘S**할 때 생성합니다. 저장 완료는 서버 ACK 뒤 표시하며, 충돌·단절 시 초안을
기기에 보관합니다. 닫으면 기존 SSH 터미널로 돌아옵니다.

도우미 설치는 사용자가 직접 검토·실행합니다. 설치/사용법·저장 의미·동시 작성 제한 및
실기기 확인 목록은 [remote/README.md](../remote/README.md)를 참고하세요.

### SSH 탭

상단 **＋**로 새 연결 탭을 추가합니다. 각 탭은 서버·로그인·한영 모드·조합·스크롤과
파일 편집 연결을 독립적으로 유지합니다. 같은 서버에도 여러 번 연결해 다른 셸 작업을 할 수 있습니다.
탭 전환 시 연결은 유지하며 비활성 터미널을 화면에서 분리해 그리기를 멈춥니다.
각 탭의 **×**는 해당 연결과 화면 자원만 종료합니다. 마지막 탭을 닫으면 새 연결 화면이 열립니다.
상단 **⌄**로 전체 터미널을 닫습니다. 앱이 백그라운드로 들어가면 모든 SSH 연결을 종료하며,
앱 재실행 시 셸 세션을 자동 복원하지 않습니다. 원격 작업 유지에는 tmux를 사용합니다.

외부 키보드에서 **⌘⇧[ / ⌘⇧]**로 이전/다음 터미널 탭으로 이동합니다.
첫 탭과 마지막 탭은 순환하며, 이동할 때 미전송 조합은 해당 탭에 그대로 보관합니다.
